┌──────────────────────────────────────────────────────────────────────────┐
│ 5. ARQUITECTURAS SOPORTADAS                                              │
└──────────────────────────────────────────────────────────────────────────┘

  [A] OFDM Tradicional:
      TX → IFFT → CP → Canal → CP-remove → FFT → Ecualizacion → RX

  [B] SIMO-MRC (1 TX, N RX):
      TX → IFFT → CP → Canal(N) → CP-remove → FFT(N)
                                       ↓
                            MRC (Frecuencia)
                                       ↓
                            Ecualizacion ZF → RX

  [C] MISO-SFBC (2 TX, 1 RX):
      DATA → SFBC → TX1, TX2 → IFFT → CP → Canal(2) → CP-remove → FFT
                                                             ↓
                                                    SFBC Decoder
                                                             ↓
                                                   Ecualizacion ZF → RX

  [D] SC-FDMA + MRC (Optima para Uplink):
      DATA → DFT → SFBC(opt) → TX(N) → IFFT → CP → Canal
                                                      ↓
                                              FFT + MRC(Freq)
                                                      ↓
                                                 Ecualizacion
                                                      ↓
                                                IDFT despread → RX

┌──────────────────────────────────────────────────────────────────────────┐
│ 7. RESULTADOS ESPERADOS                                                  │
└──────────────────────────────────────────────────────────────────────────┘

  Ganancia de Diversidad (SNR para mismo BER):
    SISO → SIMO(2 RX):     ~3-4 dB mejora
    SISO → SIMO(3 RX):     ~5-6 dB mejora
    SISO → SIMO(4 RX):     ~8-10 dB mejora

  PAPR Reduction (SC-FDMA vs OFDM):
    OFDM:                  8-10 dB tipico
    SC-FDMA:               3-4 dB tipico
    Reduccion:             ~60-80%

  Combinacion Optima (SC-FDMA + SIMO-MRC):
    • Ganancia diversidad + Reduccion PAPR
    • Recomendado para uplink LTE con restriccion de potencia
